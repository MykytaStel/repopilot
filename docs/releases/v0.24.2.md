## Highlights

- **First-run errors say what to run.** `repopilot review` no longer prints
  raw Git errors when it cannot compare anything:
  - outside a Git repository, or in a repository without commits;
  - with a `--base` or `--head` ref that does not exist, for example
    `--base origin/main` where the default branch is `master`;
  - with refs that share no history in a shallow clone, where it suggests
    `git fetch --unshallow` or `fetch-depth: 0`.
- **An empty change points at committed work.** A review with no changed files
  says so and suggests `--base origin/main`, instead of asking to expand the
  analyzable scope.
- **MCP clients pick the right tool.** Every tool description says when to use
  it and when a sibling tool fits better, every input is described, and
  `initialize` returns `instructions` that route common questions. The review
  tool's description lists the checks a change weakened. Tool schemas are
  unchanged.
- **Licenses and plugin metadata that directories detect.** The dual license
  ships as `LICENSE-APACHE` and `LICENSE-MIT`, and `glama.json` names the
  maintainer. The plugin uses literal `${CLAUDE_PLUGIN_ROOT}` hook paths and
  ships an icon, its own license, and a security policy.

## Compatibility

No breaking changes. Report schema stays `0.26`, and MCP tool names and input
schemas are unchanged. The crate now declares `rust-version = "1.90"`, the
oldest toolchain it builds with, so `cargo install` on an older Rust names the
required version. Plugin and Gemini extension version 0.24.2 works with CLI
0.24.0 or newer.

## Upgrade

```bash
cargo install repopilot --version 0.24.2 --force
npm install -g repopilot@0.24.2
```

Claude Code: `claude plugin marketplace update repopilot`, then
`claude plugin update repopilot@repopilot`. Codex:
`codex plugin marketplace upgrade`. Gemini CLI:
`gemini extensions update repopilot`.
