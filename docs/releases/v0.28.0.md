## Highlights

- **Catch weakened tests across helpers and early `exit(0)` bypasses.** Review
  follows changed Python assertion helpers through unique module imports and Go
  helpers through same-package calls in unchanged tests, reporting both the
  affected test and the helper declaration line. Test-integrity analysis also
  flags early `sys.exit(0)`, `os._exit(0)`, `process.exit(0)`, `os.Exit(0)`,
  and `std::process::exit(0)` calls inside test functions before assertions run.
- **Follow taint through one same-file helper boundary.** Taint review tracks
  untrusted arguments into a uniquely resolved same-file helper and back through
  simple identity returns in JavaScript, TypeScript, Python, and Go. A changed
  call can surface an unchanged helper sink with both locations in the evidence.
- **Track C/C++ local include impact and Rust enum-variant callers.** Quoted
  repository-local C and C++ `#include "..."` directives contribute bounded
  static dependency and impact edges. Rust review reports removed public enum
  variants when surviving module-qualified or uniquely imported constructors or
  match patterns remain in the repository.
- **Spot quiet error swallowing in four languages and enforce stronger agent stop-hooks.**
  Quiet-fallback review now covers Go empty `if err != nil {}` branches and Rust
  ignored `Err(_) => {}` arms or `let _ = fallible()` calls in error-handling
  contexts alongside JS/TS and Python. Claude Code, Codex, and Cursor stop-hooks
  now block on new taint paths and broken local API contracts in addition to
  test-integrity regressions and quiet fallbacks.
- **Cleaner human and agent review UX.** The default console review header shows
  an inline blast-radius preview of affected dependent files and a copy-paste
  `--explain-signal` command for the top signal, while filtering out noise from
  already-declared workspace dependencies and Rust `pub(crate)` re-exports.

## Compatibility

- Package version is `0.28.0`; JSON report schema remains `0.27` with additive
  review signals and evidence fields. Readers continue to accept scan reports
  with schemas `0.16`–`0.27`.
- The parsed-facts cache schema advances to 13 and the context-graph cache
  schema advances to 4, so stale cached facts from `0.27.0` are automatically
  rebuilt on first run.
- No new top-level CLI command is added. Analysis remains local and
  deterministic. Conditional C/C++ preprocessor branches, system headers,
  cross-file taint propagation, and dynamic dispatch remain outside the claims.
