## Highlights

- **More trustworthy verification.** Stale, missing, duplicate, wrong-role
  and contradictory verification outcomes cannot satisfy required proof
  obligations.
- **Safer incremental review.** Graph and parsed caches account for dirty
  source inputs, staged revisions and resolver changes, while unchanged
  context avoids redundant publication.
- **Bounded MCP analysis history.** Retained reports have revision and
  staleness metadata, immutable pagination, and a full-report payload budget.
- **Reproducible quality checks.** The pre-RC candidate passed matched
  ChangeProof screening over 30 controlled cases and the strict pinned
  11-repository zoo. These results are regression evidence, not independent
  production accuracy estimates.
- **Focused semantic groundwork.** An experimental JS/TS module-surface index
  distinguishes observed unique, ambiguous and unresolved exports. It is not
  enabled in ordinary review or used for blocking findings.

## Compatibility

- Package version is `0.29.0-rc.1`; JSON report schema remains `0.27`.
- Existing caches may rebuild on upgrade. No new top-level CLI command is
  required. Verification checks still run only when explicitly requested.
- This is a prerelease rehearsal. Once published, npm uses the `next` tag;
  stable npm `latest` and Homebrew remain unchanged. Use exact version pins.
- Independent held-out quality, first-use MCP evaluation and publication
  verification remain open. See the [evidence ledger](../engineering/v0.29-evidence-ledger.md).

## Upgrade

After publication:

```bash
cargo install repopilot --version 0.29.0-rc.1 --force
npm install -g repopilot@0.29.0-rc.1
```

To test the prerelease Action after the tag is available, pin
`MykytaStel/repopilot@v0.29.0-rc.1`. See the
[CLI guide](../cli.md) and [MCP guide](../mcp.md).
