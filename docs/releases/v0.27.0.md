title: Broader local analysis and explainable review continuation
description: RepoPilot 0.27.0 adds bounded import and API analysis across seven languages, CLI signal explanations, paged MCP review results, and deterministic impact routes.
---

## Highlights

- **Find more broken local relationships across languages.** JS/TS extensionless
  imports and unique aliases, repository-rooted Python packages, and Go
  workspace/local-replace packages now contribute bounded import evidence.
  Java and Kotlin same-package type references improve impact analysis.
- **Review more API and data-flow changes.** Rust review reports removed public
  struct fields when surviving resolved struct literals establish a direct
  caller, and recognizes grouped imports for existing function contracts. C#
  SQL analysis follows local `CommandText` receiver aliases and supported
  simple branch merges.
- **Inspect and continue a review.** `repopilot review --explain-signal ID`
  displays a retained signal; `--explain-signal-path` and
  `--explain-signal-line` select one occurrence when IDs repeat. MCP review
  calls return bounded finding/signal pages and accept the same revision-checked
  `analysis_handle` for later pages.
- **See why a file is in the blast radius.** Review outputs now include a
  deterministic shortest static-import route from changed files to affected
  dependents. The route is graph evidence, not proof of runtime reachability.
- **Keep an unrelated authorization finding quiet.** Cache-read helper names
  alone no longer count as removed authorization checks; positive boundary
  examples remain covered.

## Compatibility

- Package version is `0.27.0`; JSON report schema is `0.27`. The additive
  `impact_paths.files[].routes` field lists a deterministic shortest import
  route. Readers continue to accept scan reports with schemas `0.16`–`0.26`.
- The parsed-facts cache schema advances to 11 and its analysis identity
  changes, so stale cached facts are rebuilt.
- No new top-level CLI command is added. Analysis remains local and
  deterministic. Unsupported syntax, ambiguous resolution, dynamic imports,
  build variants and runtime-only relationships remain outside the claims.

## Upgrade

```bash
cargo install repopilot --version 0.27.0 --force
npm install -g repopilot@0.27.0
```

GitHub Action users should pin `MykytaStel/repopilot@v0.27.0`. See the
[CLI guide](../cli.md), [MCP guide](../mcp.md), and
[language-support guide](../language-support.md) for usage and limits.
