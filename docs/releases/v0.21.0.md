## Highlights

- Opt-in local history compares compatible scan and review receipts and reports new, persisting, resolved, and severity-shifted finding occurrences without uploading repository data.
- One canonical `ready`, `review`, or `blocked` merge-readiness record combines findings, changed-code signals, dependency impact, CODEOWNERS suggestions, verification steps, limitations, and an optional risk delta across console, Markdown, JSON, MCP, and GitHub Actions.
- `.repopilot/overlay.toml` provides diffable repository policy for rule severity overrides and scoped suppressions, while the generated language capability matrix now derives support claims from actual frontend wiring.
- JavaScript and TypeScript review recognizes Next.js App Router, Fastify, Hono, and NestJS request flows; Java, Kotlin, and C# gain conservative request-to-sensitive-sink coverage through their unified language frontends.
- Taint-lite now tracks exact local object fields, static array indexes, and object or array destructuring paths, preserving clean overrides and sibling isolation while keeping dynamic indexes and interprocedural propagation explicitly out of scope.

## Compatibility

RepoPilot 0.21 adds no top-level command and keeps existing gate and process exit-code behavior stable. JSON, MCP, Action, and AI-context changes remain additive, and existing scan readers continue accepting supported schema versions from `0.16` through `0.23`.

Taint analysis remains deterministic, intra-procedural, and focused on changed sink lines. Framework support covers the request and sink shapes documented by the language frontends; it does not claim arbitrary DTO model binding, custom validator or pipe semantics, heap alias analysis, dynamic indexes, or generic Rust taint.

## Upgrade

```bash
cargo install repopilot --version 0.21.0 --force
npm install -g repopilot@0.21.0
```
