---
title: Quieter agent stops and an honest first decision
description: RepoPilot 0.24.1 stops coding agents only for checks they weakened, once per session, passes a change with nothing flagged as not verified instead of always asking for review, and drops two integrity false positives.
---

## Highlights

- **Agent stop hooks stop only for weakened checks.** The Claude Code and
  Codex plugin, the Gemini CLI extension, and the Cursor hooks now stop an
  agent for a test-integrity signal, a removed auth check, an emptied test
  file, or request input reaching SQL or a shell. A dependency bump, an edited
  workflow, or a migration stays in the review report and no longer stops the
  agent.
  - Each signal is raised once per session. A signal the agent already
    restored or explained no longer stops every later turn.
  - The hooks read the JSON report, so a weakened test behind 20 other signals
    still reaches the agent, and `[review] fail_on = "definitely"` in
    `repopilot.toml` no longer disables them.
  - Session files stay out of `git status`: the hooks list
    `.repopilot/snapshot.json` and `.repopilot/cache/` in `.git/info/exclude`.
- **A first review gives an informative decision.** Without configured
  verification, a change with nothing flagged now reads `PASS (not verified)`
  instead of `REVIEW`. Any review signal, finding, coverage limit, limited
  contract, failed gate, or intent drift still keeps `REVIEW`, now with the
  evidence listed before the missing setup.
- **Two integrity false positives are gone.**
  - A CI test command rewritten as another command of the same kind
    (`npm test` → `npm run test:ci`) is no longer a removed check.
  - Skipping every test in a JS/TS file is reported as skipped tests, not also
    as an emptied test file.

## Compatibility

No breaking changes. Report schema stays `0.26`. `decision.verdict` keeps its
values; without configured verification, a `REVIEW` whose only reasons are the
missing setup becomes `PASS` with a "not verified" limitation, while
`change_proof.verdict` stays `REVIEW`. Plugin and Gemini extension version
0.24.1 works with CLI 0.24.0 or newer.

## Upgrade

```bash
cargo install repopilot --version 0.24.1 --force
npm install -g repopilot@0.24.1
```

Claude Code: `claude plugin marketplace update repopilot`, then
`claude plugin update repopilot@repopilot`. Codex:
`codex plugin marketplace upgrade`. Gemini CLI:
`gemini extensions update repopilot`.
