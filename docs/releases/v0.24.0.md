---
title: Honest Green — see the checks a change weakened
description: RepoPilot 0.24 reports when a change turns CI green by weakening the checks that judge it — skipped or removed tests, lost assertions, new suppressions, relaxed CI and coverage gates — lists them right after the review decision, and runs the same review automatically at the end of a coding-agent session.
---

## Highlights

- **Weakened checks are reported.** A new `integrity` signal family names each
  check a change weakened, with file and line:
  - tests that were focused (`it.only`), skipped, or removed;
  - tests that lost assertions, followed through same-file helpers;
  - new lint, type, and coverage suppressions;
  - relaxed CI and tool gates: `continue-on-error`, `|| true`, coverage floors
    lowered in config or on the command line, strict mode turned off;
  - entries that silence RepoPilot itself.

  The console lists these checks right after the decision, and the GitHub
  Action's pull request summary lists them first.
- **Agent sessions get the same review before they finish.**
  - `repopilot snapshot` marks a starting point.
  - The RepoPilot plugin for Claude Code and Codex, the Gemini CLI extension,
    and the Cursor hooks review the session when the agent tries to stop. If a
    check was weakened, they block the stop once and send the agent the list.
  - Copilot's coding agent gets setup steps and an MCP entry, and any agent
    that reads `AGENTS.md` gets a ready-made snippet.
- **Priorities follow severity.** Under `risk-v4`, review context can no longer
  lift a medium-severity finding to `P0`. Coverage limits carry named reasons,
  and proof obligations are grouped by role.
- **Measured, with the limits stated.**
  - A corpus of 358 real pull requests found unexplained weakening to be rare:
    0 of 126 merged agent pull requests and 2 of 170 merged human pull requests
    after maintainer review.
  - Held-out precision: suppressions 5/6, assertions removed 2/3, removed tests
    5/8 when combined with deleted test files.
  - An agent eval with Codex found that it did not weaken tests on ordinary
    tasks. When a test contradicted the documented behavior, it bent the code
    to the test instead, and RepoPilot did not report that.
- **Large reviews stay fast.** In the recorded macOS ARM64 run, integrity
  analysis took 0.47% of a 20-file review (655 ms total). The CI run recorded
  5.2% (141 ms total), within the 10% budget. Large-diff reviews read both
  revisions in batches.

## Compatibility

RepoPilot 0.24 adds no top-level command. The following schema declarations
describe the `v0.24.0` source, not future releases. The scan-reader
input range is inclusive.

| JSON surface | Schema version(s) |
|---|---|
| `scan` | `0.26` |
| `baseline-scan` | `0.26` |
| `review` | `0.26` |
| `receipt` | `6` |
| `scan-reader input` | `0.16–0.26` |

Review JSON changes are additive:

- `integrity.*` signal kinds in `tiered_signals`;
- `review_timings.integrity_us`.

Changes in behavior:

- **Signal tiers.** A committed focus marker is definitely sensitive. Every
  other integrity signal is maybe sensitive, so
  `--fail-on-review definitely` does not fail on them.
- **Priorities.** `risk-v4` changes some priorities compared with 0.23. See
  the [risk-v4 calibration](../engineering/risk-v4-calibration.md).
- **Snapshots of a dirty working tree.** `repopilot snapshot` now also pins a
  baseline commit of the uncommitted files, so
  `review --since-snapshot` covers only the work done after the snapshot.
- **The GitHub Action is renamed "RepoPilot Review".** The
  repository and every input are unchanged; pin the release with
  `uses: MykytaStel/repopilot@v0.24.0`.
- **Hooks use the CLI on `PATH`.** The plugin, extension, and hooks need the
  0.24 CLI to report integrity signals.

Quality evidence remains scoped to what was measured. The corpus and the
agent eval are small, and their confidence intervals are wide. See the
[v0.24 release scorecard](../engineering/v0.24-release-scorecard.md) and the
[integrity corpus report](../../tests/integrity/REPORT.md).

## Upgrade

```bash
cargo install repopilot --version 0.24.0 --force
npm install -g repopilot@0.24.0
```

In Claude Code, add the plugin with
`/plugin marketplace add MykytaStel/repopilot` and then
`/plugin install repopilot@repopilot`.
