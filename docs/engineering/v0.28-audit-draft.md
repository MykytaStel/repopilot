# RepoPilot 0.28.0 — baseline audit

Status: baseline audit for the approved 0.28 scope; not implementation evidence.

Audit date: 2026-11-17. Baseline: `origin/main` at `ad0a4453`; stable
`v0.27.0` tag at `921d87ff`. This is a targeted review of current release
records, language capabilities, review signals, and available issue metadata.
It is not a full code, security, precision, or usability audit. No tests, zoo
scans, benchmarks, or independent user observations were run for this audit.

## Evidence for a larger 0.28 scope

- 0.27.0 shipped bounded import, public API, test-integrity, taint, MCP, and
  review-evidence improvements. The current code and release record are the
  baseline; these features must not be proposed again as new.
- Cross-file changed assertion-helper attribution currently targets JS/TS.
  Python, Go, and Rust have same-file integrity analysis that could be extended
  after a language-specific feasibility and real-case review.
- The taint engine documents itself as intra-procedural. Six frontends have
  taint tables; safe flow through a local helper boundary is a distinct next
  capability, not a claim about general interprocedural analysis.
- C and C++ are detected, but their files have no language frontend. The
  generated support page groups C/C++ headers under “Import-aware”, while the
  frontend registry has no C/C++ entry and resolver tests explicitly exclude
  `.cpp` and `.h`. 0.28 must wire real local include edges and make the support
  matrix reflect the resulting capability; the current label is not evidence
  that these files already resolve.
- Rust public-contract review covers removed functions, function arity, and
  public struct fields. Public enum-variant removal is not listed among the
  current contracts.
- The rule scorecard currently has default-profile zoo labels for 6 of 56 rules;
  most rules remain unmeasured. This supports a broader evidence workstream, not
  a broad precision claim.
- The 0.27.0 release passed public-channel verification after manual Homebrew
  formula recovery, but its automatic Homebrew update failed because the
  configured credential was rejected. This needs owner-side recovery before a
  future release.
- The connected repository issue search returned no open product issues. The
  result does not establish that users have no problems.

The approved feature slices, acceptance criteria, evidence gates, and
sequencing are in the [0.28 roadmap](../roadmap/v0.28.md). The status ledger is
[here](v0.28-evidence-ledger.md). Plans do not count as implementation or
release evidence.
