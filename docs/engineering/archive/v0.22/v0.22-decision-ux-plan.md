# v0.22 Decision UX Implementation Plan

> Execute this plan with the `executing-plans` skill and stop at each verification checkpoint.

**Goal:** Make RepoPilot's scan and review output honest, compact, and immediately actionable without redesigning the CLI.

**Architecture:** Preserve `health_score` as the visible-profile score, add a stable pre-visibility `maintainability_score`, and render both through the existing output adapters. Bound only the human default review inventory; machine-readable and full-detail output remain complete.

**Tech stack:** Rust 2024, serde, clap, existing console/Markdown/HTML renderers and integration fixtures.

**Spec:** `docs/engineering/v0.22-decision-ux-spec.md`

**Constraints:** Use TDD, preserve older report parsing, keep ordering deterministic, update `[Unreleased]`, and do not commit or push until requested.
