# v0.25 Evidence Ledger

Status: approved technical scope, implementation started 2026-10-06. The
[0.25 scope](../roadmap/v0.25.md) owns acceptance criteria; this ledger owns
status and evidence. Published 0.24.3 behavior and distribution belong in the
[0.24 ledger](v0.24-evidence-ledger.md).

Statuses: open, in-progress, verified, accepted. Planning and source inspection
do not close an implementation row. Each PR updates its own row; a measured
claim names its denominator, version, selection method, and limitations.

## Baseline

- Source: 0.24.3, main commit 5544fd07110d42807640ed8bf259c98f1637e3a6.
- The 2026-10-05 source gate passed: formatting, all-target/all-feature clippy,
  1,988 Rust tests (one ignored released-reader probe), 400 Python tests,
  release contract with local zoo, P1 self-scan, and review performance.
- This is historical source evidence. A future change reruns its applicable
  checks; installation, native client behavior, and detector accuracy remain
  separate evidence.
- [Rule coverage](rule-scorecard.md) currently has default-profile labels for
  6/54 rules. [Contract evidence](review-contract-evidence.md) is synthetic;
  neither establishes broad production precision or recall.
