## Baseline (2026-09-25)

- `v0.23.0` is published and verified by digest on GitHub Releases, crates.io,
  npm (root and five platform packages), and Homebrew
  (`verify-publication.yml` run 36140497616).
- crates.io publishes through Trusted Publishing from the `release`
  environment; a no-op `publish-crates.yml` run for `v0.23.0` authenticated
  without a token and skipped the matching version (run 36158121757).
- npm Trusted Publishers for all six packages list both `release.yml` and
  `publish-npm.yml` with environment `npm` and publish permission; automatic
  tag publishing is not yet proven by a run.
- Risk formula `risk-v3`: priority is a score threshold (P0 ≥ 90, P1 ≥ 70,
  P2 ≥ 40); a MEDIUM finding can reach 94 from context signals alone.
- The committed rule scorecard has default-profile evidence for 6 of 54 rules.
