## Evidence rules

- Record commands, commit, environment, denominators, and limitations for every
  measured claim.

  precision or recall.
- If a scope changes default-visible findings, update the zoo snapshot and
  reviewed expectation labels. Strict-only labels come from deterministic
  samples; hand-picked anchors remain separate.
- Do not mark an item verified from a design, passing unit fixture, or prior
  release's gate. Each status needs evidence for the current 0.28 change.
