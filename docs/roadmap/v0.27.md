# v0.27 — language analysis and review evidence

status: release preparation complete; publication pending

[Release notes](../releases/v0.27.0.md) · [Evidence ledger](../engineering/v0.27-evidence-ledger.md)

RepoPilot 0.27.0 extends bounded local analysis in Rust, JS/TS, Python, Go,
C#, Java and Kotlin, and makes review evidence easier to inspect from the CLI
and MCP. It remains a local heuristic analyzer: graph edges do not prove
runtime reachability, and syntax analysis does not replace compilers or tests.

## Shipped

- Resolve additional local imports and package references in JS/TS, Python,
  Go, Java and Kotlin; add Rust public struct-field contract evidence and
  grouped-import support.
- Follow C# `CommandText` receiver aliases and conservatively merge supported
  conditional assignments.
- Explain a review signal by ID and optional occurrence locator from `review`;
  continue MCP review findings and signals through revision-checked pages.
- Include deterministic shortest static-import routes in review impact output.
- Advance the JSON report schema to 0.27 while retaining readers for schema
  0.16–0.26.
- Narrow an authorization-removal false positive for cache-read helper names.

## Evidence still open

Passing synthetic and integration tests establish the supported syntax and
safe controls, not production precision or recall. Independent first-use
observations and live-client MCP consent checks were not available for this
release. See the [evidence ledger](../engineering/v0.27-evidence-ledger.md)
for the verified gates and residual limits.
