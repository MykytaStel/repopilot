## Release criteria

Proposed targets: precision >=95% for supported blocking families and recall
>=85% for priority mutations with explicit denominators and confidence
intervals. Treat underpowered samples as unmeasured. Require semantic parity
across repeat/thread/cache paths and <=10% unexplained matched performance
regression; keep existing absolute budgets. Target five independently observed
first reviews. An unmet gate stays open and is not waived silently.

No broad new language support, hosted analysis, LLM calls, or schema-breaking
changes. Follow existing signal and security contracts. See [ledger](../engineering/v0.29-evidence-ledger.md)
and [v0.30 scope](v0.30.md).
